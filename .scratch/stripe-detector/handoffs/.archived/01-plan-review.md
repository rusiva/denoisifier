## Findings

- [x] B1 break: the score is a scale-free ratio (`P_peak / median(P in band)`, plan §7.7), so on a profile-only frame with little or no noise it is driven by deterministic leakage (envelope-estimate mismatch, `env > 0.1·max` cut-off edge, asymmetric-profile kink) at the low-frequency edge of the band, not by noise. Prototype, m = 0, seeds 0–9: noise 0.01 → scores 22–37; noise 0.003 → 178–233; noise 0.001 → 1391–1651; **noise 0 → ~68,800 every seed**, peak always at period ≈ 19 px (band edge). Striped frames (m = 0.6, noise 0.01) score ~1.5e7. The plan's log-midpoint threshold (§7.8) lands near ~2e4, so a noise-free profile-only frame is reported **striped**. The ticket AC "A frame with only the profile is not striped" reads naturally as the noise-free case, and "low noise" is the ticket's own regime; the plan only tests noise = 0.01 (§9 `test_profile_only_frame_is_not_striped`), so the suite passes while the criterion fails. → Plan change: parametrise the profile-only test over noise ∈ {0, 0.001, 0.01} (and the striped test over at least noise ∈ {0, 0.01}); change the method so leakage cannot win, e.g. an amplitude gate (estimated modulation amplitude from the peak height must exceed a small floor such as 0.05) or a score that is anchored to an absolute noise/leakage floor rather than a pure ratio; settle the choice with P1 before slice 4.
